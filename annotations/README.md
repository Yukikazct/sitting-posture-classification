# 标注交接文件

这里保存适合随 Git 同步的候选、来源、人工标签与审计元数据；不包含人物照片、视频、模型或虚拟环境。

- `archive/`：2026-10-26 保存的旧四类人工历史与 154 条开发清单。原始 JSON/CSV 逐字节复制，旧机器绝对路径仅用于溯源，不表示本机文件存在。`snapshot_index.json` 记录原件校验和。
- `mpii/priority_candidates_v2.{csv,json}`：236 条待人工核实的候选，主标签为空；不是已确认后仰/坐姿数据。
- `mpii/sample_acquisition.json`：原设备取得 12 张样图的记录，不包含图像；下载状态是历史事实，不代表 clone 已带图。
- `source_evidence/`：备选来源的实际文件核查摘要。

迁移流程已用真实本地图片验证：恢复 COCO 240 个候选及 133 条历史决策、同学批次 91 个候选及 91 条历史决策，决策内容完全一致。MPII 的 12 张来源样图中只有 3 张位于 236 条优先清单，试运行成功加载这 3 张，其余 233 条报告缺图；不能将 12 张样图数与候选交集混为一谈。

请从 [换设备继续标注](../docs/换设备继续标注.md) 开始。原始审核历史绑定候选文件 SHA256，不能手改原候选路径后直接重用旧审核文件；准备脚本在新目录创建副本并记录迁移。

旧清单 `training_ready=false`，`split` 留空。五类审核输出尚不能直接交给原四类训练命令。
