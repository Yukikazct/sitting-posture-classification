# 框架验证记录

日期：2026 年 10 月 23 日。此记录仅证明程序框架的可运行性，不是坐姿分类实验结果。

## 验证环境

- Apple M5 Pro，24 GB 统一内存。
- Python 3.9.6、PyTorch 2.8.0，MPS 可用。
- 当前未安装 Ultralytics / OpenCV，未准备本地 YOLO11n-pose 权重。

| 检查 | 实际证据 |

| 数据边界 | 测试覆盖人员/视频/组/图像的跨集合泄漏、传递分组、空清单与拒绝覆盖 |
