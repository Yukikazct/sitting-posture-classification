# 坐姿标注与清单规范

> 本文保留旧四类训练框架的规范。2026-10-26 起，新一轮共同标注按 [五类统一标准 v2](坐姿统一标注标准_v2_建议稿.md) 校准；审核页显式使用 `--label-schema posture_v2`。旧记录不自动升级，五类训练实现待迁移。见 [当前进度](当前进度与数据集选择.md)。

版本：初稿。正式采集前用少量试标样本检查人员之间是否理解一致，再固定版本。标签来自人工观察原图或原视频，不由本项目角度规则或模型预测生成。

## 四类标签

| 标签 | 中文 | 人工判定依据 |
|---|---|---|
| `upright` | 端正 | 人处于坐姿，头部与躯干自然直立，无明显低头、躯干前倾或左右倾斜。 |
| `head_down` | 低头 | 躯干基本保持端正，头颈明显向下弯曲，面部朝向下方；不能只凭鼻子的图像位置判定。 |
| `forward_lean` | 上身前倾 | 上半身整体向身体前方倾斜，肩部相对髋部前移；应结合躯干轮廓和机位判断。 |
| `side_lean` | 侧倾 | 上半身明显向身体左侧或右侧倾斜；左右方向合并为一类。 |

复合动作、转身、站立、躺卧、严重遮挡、多人重叠及无法有把握判断的图像不强行归类。将剔除原因记入人工审计记录，暂不放入四类训练清单。连续视频中的遮挡和离座仍需保留，用于检查系统是否显示“暂无法判断”并清除异常计时。

“暂无法判断”是系统拒识状态，不是第五个训练类别。不要为了凑齐类别数量而降低判定标准。

## 视角与复核

- 主机位建议约 45° 斜前方，尽量完整拍到头、双肩与双髋；正面和约 75° 侧面分别记录。
- 建议 `view` 使用 `front`、`oblique`、`side`、`unknown`。无法确认机位时填 `unknown`，不要根据预测结果反推视角。
- 2D 关键点不能直接还原深度或真实颈椎角度。正面可能看不清前倾，侧面可能遮住远侧肩髋；无法区分时剔除，困难视角的检测拒识在最终评估中照常计入。
- 抽取至少 20% 样本做第二次人工复核，尽量覆盖所有类别、视角和来源。分歧通过查看原始上下文讨论解决；仍不确定则剔除，并保留初标、复核、最终决定和原因。

## 图像清单 CSV

统一使用 UTF-8 CSV，首行必须包含以下十列。`data/manifest.csv` 是仅含表头的起始模板；正式数据准备前运行审计会提示空清单。

| 字段 | 填写方法 |
|---|---|
| `sample_id` | 全局唯一，例如 `spd_image_000123`、`self_p02_v01_f0030`。 |
| `image_path` | 图像路径；相对路径相对于当前 CSV 所在目录解析。 |
| `label` | 四类英文标签之一，顺序为 upright/head_down/forward_lean/side_lean。 |
| `split` | 未划分时留空；正式使用仅允许 `train`、`val`、`test`。 |
| `subject_id` | 可追溯的真实人员编号；未知则留空，禁止编造人员身份。 |
| `video_id` | 来源视频编号；独立静态图片可留空。 |
| `group_id` | 同一原图及其裁剪、同次拍摄或不可独立场景的编号；不能填类别名。 |
| `view` | 已知机位类别，建议使用上表约定。 |
| `source` | 数据来源，例如 `spd_yolo`、`coco`、`self`。 |
| `timestamp_sec` | 视频帧的原视频秒数，有限且非负；独立静态图片留空。 |

**身份编号必须加来源前缀。** 例如 `spd_person_01` 与 `self_person_01` 表示不同来源的不同人员；不要都写成 `01`。视频和组编号也如此。若确认同一人在多个来源出现，应使用统一的真实身份编号，以阻止跨集合泄漏。

以下仅示范格式，不是已采集数据。假设清单保存为 `data/manifest.csv`，`raw/...` 将解析到 `data/raw/...`：

```csv
sample_id,image_path,label,split,subject_id,video_id,group_id,view,source,timestamp_sec
self_p01_v01_f0030,raw/self/p01/v01/frame0030.jpg,upright,,self_person_01,self_p01_video_01,self_p01_capture_01,oblique,self,1.0
```

## 划分与采集

1. 审计官方划分；可验证且不存在已知泄漏时优先保留。`split` 命令会拒绝重新划分已有非空分配的清单。
2. 自行划分时先按人员、视频、原图/拍摄组确定归属，再抽帧。框架将任意相同的 subject/video/group/image 关系传递合并，整组近似按 70%/15%/15% 分配，至少需要三个独立组。
3. 检查图片内容的重复、近重复与裁剪来源。仅改文件名不能让同一原图跨集合；路径和身份检查不能替代图像内容去重。
4. 查看各集合类别数，不能为了改善测试指标交换样本。公开集身份缺失必须在报告中披露，不能据此宣称跨人泛化。
5. 自采约四名获同意参与者：一人固定用于验证，另外三人固定用于测试和演示，同一人员不能参与训练或跨集合。每人在三个视角重复四类动作，并采集正常、短暂调整、持续异常、遮挡和离座视频。

## 连续事件标注

`data/events.csv` 的字段为 `video_id,start_sec,end_sec,label,split,subject_id,view`。人工观看原视频，以视频时间标注半开区间 `[start_sec,end_sec)`，记录端正区段和异常区段；相邻区段不能重叠，起止秒数必须能回溯到原视频。

持续异常事件按任一非端正姿势连续维持至少 3 秒定义；不同异常类别连续切换仍按同一段异常过程检查提醒。短于 3 秒的调整单独保留，不算应该触发的持续异常事件。遮挡、离座和不确定区间单独记录为不可判定区间，用于检查拒识和计时复位，不赋予四类真值。
