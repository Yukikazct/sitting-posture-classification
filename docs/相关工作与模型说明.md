# 首阶段阅读记录与模型选择

核验日期：2026 年 10 月 23 日。本文记录原论文与官方说明，不将第三方成绩写作本项目实验结果。访问副本和实际网络错误保存在 `runs/stage1/sources/`。

## 1. COCO：作为 RGB 及人体关键点来源

**参考：** T.-Y. Lin et al., “Microsoft COCO: Common Objects in Context,” ECCV, 2014。

- [微软研究院原论文介绍](https://www.microsoft.com/en-us/research/publication/microsoft-coco-common-objects-in-context/)已访问，核验题名、作者和 ECCV 2014；arXiv 入口本次连接被重置，保留错误，未把它写为下载成功。
- [COCO 官网](https://cocodataset.org/)与[官方许可条款](https://cocodataset.org/dataset/termsofuse.htm)用于数据来源和授权核查。
- 已取得官方 2017 验证集关键点与实例 JSON。关键点文件含 5,000 张图像和 11,004 条人体标注；这些数量不等于坐姿样本数量。
- COCO 的关键点/检测标注没有本项目的“端正、低头、前倾、侧倾”标签。膝关节等几何条件仅用于产生待审候选，不能生成坐姿真值。
- 原始图片按每张 `images[].license` 及其来源保留许可；COCO 注释采用 CC BY 4.0，不能把注释许可套给所有图片。

**本项目使用方式：** 获取可辨认坐姿的真实 RGB 图片，独立试标并复核；保留原图分组，披露缺少人员身份标签的限制。公开验证集图片目前只用于可行性检查，不参与正式模型训练。

## 2. MPII：比较人体姿态数据的适用范围

**参考：** M. Andriluka, L. Pishchulin, P. Gehler, and B. Schiele, “2D Human Pose Estimation: New Benchmark and State of the Art Analysis,” CVPR, 2014。

- [MPII 官方数据页](https://www.mpi-inf.mpg.de/departments/computer-vision-and-machine-learning/software-and-datasets/mpii-human-pose-dataset)已访问并保留引用原文。
- 官方介绍约 25,000 张图像、40,000 名带人体关节标注的人物及 410 种活动；活动标签也不能直接当作四类坐姿标签。
- 不同关键点定义不能直接混入当前 COCO 17 点特征缓存；需要明确映射与可见性处理。本阶段未下载 MPII，也不宣称它已满足四类数据需求。

## 3. YOLO11n-pose：冻结的关键点提取器

**参考：** Ultralytics, “Ultralytics YOLO11” 与 “Pose Estimation,” 官方技术文档。

- [YOLO11 模型页](https://docs.ultralytics.com/models/yolo11/)和[姿态任务页](https://docs.ultralytics.com/tasks/pose/)均已实际访问。
- 本项目明确采用 `yolo11n-pose.pt`，输出 COCO 格式 17 个二维关键点及置信度，默认输入尺度 640。关键点的 x/y 为图像坐标，不是真实三维身体角度。
- 官方文档当前的通用姿态表可能展示后续 YOLO 系列；不把其他系列的参数、FLOPs 或速度误写为 YOLO11n-pose。
- 官方已说明 YOLO11 的引用方式及 DOI 尚待补充；本项目引用官方文档和软件来源，不编造同行评审论文或 DOI。
- 权重取自 [Ultralytics 官方 assets v8.3.0 release](https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n-pose.pt)，实际文件 SHA-256 与获取过程见 `models/yolo11n-pose.provenance.json`。
- [官方许可说明](https://www.ultralytics.com/license)提供 AGPL-3.0 与 Enterprise 路径；已保留官方许可副本。本项目不将第三方模型或其授权表述为原创成果。

**本项目使用方式：** 提取器冻结，只训练小型 MLP。先验证鼻、肩、髋的可靠性，再计算 25 维特征；多人或必需关键点不足时拒识。模型本机速度与内存以本次真实测量记录为准，不引用官方其他硬件速度替代。

## 4. 分类器与提醒的工程选择

MLP 使用 `25 → 64 → 32 → 4`，用于研究少量归一化姿态特征是否优于人工角度阈值。该网络是本项目要实际训练的神经网络模块；冻结的姿态模型本身不是四类分类器。

EMA 采用 `q_t = α p_t + (1−α) q_(t−1)`，初始 `α=0.3`。它是标准概率平滑方法，作为减少短暂抖动的工程对照，不宣称为新网络。提醒按实际秒数计时，并同时比较误提醒、事件召回与延迟；平滑并不保证指标一定提升。

二维特征会随摄像角度变化。正面图像对身体前后变化可能含糊，侧面图像可能遮住远侧肩、髋；这属于观测限制，应通过视角分组与拒识统计呈现，不能用不可靠的坐标补全掩盖。

## 本阶段结论

路线在工程上由“真实 RGB → 官方姿态模型 → 可用关键点”进行验收；四类标签质量和每类样本量需要独立证据。SPD_YOLO 的骨架图、重复划分及类别不匹配已另列[数据审计](数据可用性审计.md)，不会据其官方验证成绩启动本项目正式训练。
