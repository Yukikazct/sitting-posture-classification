# 换设备继续标注

更新：2026-10-26。当前进度与选择理由见 [当前进度与数据集选择](当前进度与数据集选择.md)。本页命令均从仓库根目录运行，标注只需要 **Python 3.9+**，不需要安装 PyTorch、CUDA 或 YOLO。

## 1. 获取这次上传的分支

```powershell
git clone --branch feat/public-dataset-review https://github.com/Yukikazct/sitting-posture-classification.git
cd sitting-posture-classification
python --version
```

已有仓库时先保存本机改动，再 `git fetch origin` 和 `git switch feat/public-dataset-review`。不要直接覆盖另一位标注者正在修改的文件。

## 2. 建议你标 MPII，同学继续 COCO

先阅读 [五类统一标准](坐姿统一标注标准_v2_建议稿.md)。下载 [MPII 官方 RGB 包](https://datasets.d2.mpi-inf.mpg.de/andriluka14cvpr/mpii_human_pose_v1.tar.gz)（约 12.1 GB；官网标 12.9 GB），使用解压软件解压。解压后的 `images` 目录应含 `021233911.jpg` 等九位数字文件名。

也可以单独传送原设备的 `data/raw/mpii/images/` 后试标少量图；原设备目前仅有 12 张来源核查样图，未必全部属于 236 条优先清单。准备工具只加载清单中实际存在的图片；缺少图片会报告，不能当成已取得全部数据。

假设图片位于 `D:\datasets\mpii\images`：

```powershell
python scripts/prepare_annotation_workspace.py --source mpii --images-dir "D:\datasets\mpii\images" --output runs/handoff/mpii
python scripts/review_candidates.py --candidates runs/handoff/mpii/candidates.json --output runs/handoff/mpii/review.json --label-schema posture_v2 --open-browser
```

macOS/Linux 同样使用 `python3` 和对应目录。浏览器访问终端显示的 `http://127.0.0.1:8765/`；可以在 Chrome 打开。五类审核快捷键为 1–5，另有排除、待定。每条提交会写入本机 `review.json`，不是保存在浏览器缓存里。再次打开时直接运行第二条命令；不要重建已有工作目录。

236 条候选分为 181 条日常/课堂相关和 55 条 reclining。**reclining 不是 back_lean 标签**，躺卧必须排除。多人图先确认人物，备注记录 `target: ...; bbox=[x,y,w,h]`（原图像素坐标）；网页目前不支持绘制/编辑目标框，目标无法确认时保留待定。

## 3. 继续 COCO 或原同学批次

COCO 原图可从 COCO 官方图片源获取。无需下载整套 COCO，运行以下工具可按归档清单逐张取得原图并核验 SHA256：

```powershell
python scripts/download_coco_review_images.py --output data/raw/coco2017/images
python scripts/prepare_annotation_workspace.py --source coco --images-dir data/raw/coco2017/images --output runs/handoff/coco-v2
python scripts/review_candidates.py --candidates runs/handoff/coco-v2/candidates.json --output runs/handoff/coco-v2/review.json --label-schema posture_v2 --open-browser
```

这是按 v2 **重新审核**，不会把旧四类决策自动确认成 v2。COCO 使用原图与原有目标框显示两栏，不依赖旧机器裁剪路径。

同学旧批次需单独传送原始 `back_lean` 文件夹/压缩包，再执行：

```powershell
python scripts/prepare_annotation_workspace.py --source classmate --images-dir "D:\datasets\back_lean" --output runs/handoff/classmate-v2
python scripts/review_candidates.py --candidates runs/handoff/classmate-v2/candidates.json --output runs/handoff/classmate-v2/review.json --label-schema posture_v2 --open-browser
```

原目录下 43 张后仰隔离图并不在此前的 91 条审核队列中；恢复这 91 条不会自动加入那 43 张。其文件信息仍在 `annotations/archive/classmate/source_manifest.json` 与 `held_records.csv`，后续须单独定位、去重并纳入新队列。

仅需查看/延续**旧四类**记录时，使用一个新输出目录并加 `--resume-v1`：

```powershell
python scripts/prepare_annotation_workspace.py --source coco --images-dir data/raw/coco2017/images --output runs/handoff/coco-v1 --resume-v1
python scripts/review_candidates.py --candidates runs/handoff/coco-v1/candidates.json --output runs/handoff/coco-v1/review.json --open-browser
```

旧历史恢复要求候选图全部存在，保持全部 `records/history`；原始归档不改。`classmate` 也可用同样参数恢复旧记录。五类训练尚未迁移，不能将 v2 CSV 直接作为当前四类模型输入。

## 4. 把新设备的标注同步回来

关掉标注服务或完成保存后，把工作队列、完整审核 JSON 与准备报告复制进一个**本人独有**的目录，例如：

```powershell
New-Item -ItemType Directory -Force annotations/submissions/mpii-zhangsan
Copy-Item runs/handoff/mpii/*.json annotations/submissions/mpii-zhangsan/
git add annotations/submissions/mpii-zhangsan
git commit -m "data: add MPII human annotation progress"
git push origin feat/public-dataset-review
```

将 `zhangsan` 换成自己的标注者标识。浏览器也可导出完整审核 JSON 和 CSV；**完整 JSON 必须保留**，它含修订历史。工作图片仍从官方来源或私下文件传输获取，不提交原图。

`runs/`、原图、模型和虚拟环境默认被 Git 忽略；仅在 `runs/` 中保存不会自动同步。两人分别使用独立目录/分支；push 被拒绝时先获取并协调远端新提交，禁止强推覆盖对方记录。
