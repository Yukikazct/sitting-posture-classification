# 坐姿统一标注标准 v2（建议稿）

日期：2026 年 10 月 26 日。用途：供两位标注者校准并共同维护一套数据集。本稿提出五类规范；现有四类软件配置和历史人工标注尚未按此迁移。

实现状态更新：审核页已支持 `--label-schema posture_v2` 五类新审核。旧人工记录不自动升级；训练模型、规则基线、训练清单校验和演示仍为四类。换设备请见 [操作指南](换设备继续标注.md)。

建议使用五个主标签：`upright`、`head_down`、`forward_lean`、`side_lean`、`back_lean`。每个目标人物只有一个主标签，同时可记录头部状态。课程第 05 题描述低头、上身前倾、侧倾等可见姿势，没有限定必须采用四类。

## 1. 标注对象和共同前提

- 一条样本对应原图中的一个明确目标人物。多人图先确认同一个人物，并记录目标框；不能给整间教室共用一个姿态标签。
- 必须能确认目标人物处于座椅、凳子、长椅等支撑上的坐姿。站立、蹲姿、躺卧、骑行等不进入这套课堂/日常坐姿分类。
- “学生”“上课”“写字”“玩手机”“睡觉”用于检索和记录场景。最终类别依据可见的头颈与躯干姿势。
- 学生课堂是重点应用场景，其他已收集的坐姿照片可保留来源和场景信息作为补充。两人比较结果时使用同一份样本清单与划分；课堂子集可单独报告。
- 图片不足以判断坐姿、目标人物或关键姿态时，记录待定及原因。遮挡、低清、无目标、非坐姿、卡通、重复等是审核状态，不作为额外姿态类别。

## 2. 五类定义

| 主标签 | 统一中文名 | 必须看到的主要证据 | 易混边界 |
|---|---|---|---|
| `upright` | 自然直坐（端正） | 躯干整体基本直立，头颈无明显下弯，身体没有明显前后或左右倾斜 | 自然接触椅背仍可能是端正；面对镜头、正在听课都不能单独作为证据 |
| `head_down` | 低头 | 躯干基本直立，主要变化是头颈明显向下弯曲 | 眼睛向下看不等于低头；写字、看手机时也可能同时有明显前倾 |
| `forward_lean` | 躯干前倾（含明确趴桌） | 躯干整体朝身体前方倾，肩部相对髋部明显向前；仍处于坐姿的上身伏桌可归此类 | 只低头、轻微圆肩或图片标题写“驼背”不足以判前倾；趴桌但躯干被完全遮住时待定 |
| `side_lean` | 躯干侧倾 | 躯干整体向身体左侧或右侧倾斜；左右合并为同一类 | 只歪头、转头、转身、侧面拍摄或照片本身倾斜不等于侧倾 |
| `back_lean` | 躯干后仰 | 仍坐在支撑面上，躯干整体相对髋部明显向身体后方倾 | 背部碰到椅背、仅抬头不等于后仰；明显躺卧另行排除 |

“明显”由共同校准的正例、边界例和反例约束。观察身体朝向、肩—髋关系及桌椅环境，不直接按画面的左右方向判断人体前后。不得用一套固定二维角度阈值自动生成标签，再用相同阈值作为对比方法验证这些标签。

## 3. 每张图按同一顺序判断

1. 找到同一目标人物，确认属于坐姿，检查图像是否足够判断。
2. 先看躯干：若有清楚的主要倾斜方向，分别标为前倾、后仰或侧倾。
3. 躯干基本直立时，再看头颈：明显向下弯曲为低头；头颈也自然直立为端正。
4. 多个躯干方向都明显且难以确定主要方向，或关键部位不可见，标待定并说明原因。不设随意的“侧倾优先于前倾”次序。

推荐辅助字段 `head_state`：`down`（明显低头）、`not_down`（无明显低头）、`unknown`（看不清）。辅助字段帮助记录重叠姿态，五类主标签仍用于单标签分类。

### 复合姿势的新约定

| 可见情况 | 主标签 | 辅助头部状态 |
|---|---|---|
| 低头写字，躯干基本直立 | `head_down` | `down` |
| 低头写字，整个躯干明显前倾 | `forward_lean` | `down` |
| 坐在椅子上，上身明显伏向桌面 | `forward_lean` | 按图像记录，不因“睡觉”推断 |
| 躯干明显侧倾，同时低头 | `side_lean` | `down` |
| 躯干明确后仰，同时低头看手机 | `back_lean` | `down` |
| 前倾和侧倾都明显，无法一致决定主要方向 | 待定 | 按可见性记录 |
| 身体直立，仅头歪向一侧 | 不据此判侧倾；若无法符合其余主类则待定 | 按可见性记录 |
| 靠着椅背但躯干仍基本直立、头颈自然 | `upright` | `not_down` |

这是对旧规范“复合姿势暂不进入四类”的有意识调整：头部下弯与一个明确躯干方向可以共同记录；难以分解的多方向躯干姿态继续待定。

## 4. 两人如何校准

1. 从共享候选中挑 30–50 张，覆盖五类、不同视角及上述易混边界；稀缺类别优先覆盖全部清楚样例。
2. 两人使用相同目标框，独立填写主类、头部状态、是否待定及简短理由。校准时隐藏另一人的标签和原文件夹名。
3. 比较分歧，重点检查低头/前倾、端正/后仰、歪头/侧倾。共同为每类固定清楚正例和反例；修订规则后再用未讨论过的小批样例验证理解。
4. 冻结 `label_schema_version=posture_v2` 后再批量复核。至少抽取 20% 进行第二次人工复核；侧倾、后仰、复合边界及已有分歧重点复核。
5. 保留同学原标签、旧项目标签、各自独立判断、最终标签及修改原因。看过他人标签后作出的修改应记作复核/协商，不写成独立双人一致性结果。

## 5. 现有数据的迁移顺序

1. 对已有人工保留清单按 v2 重新核对标签边界，尤其是低头、前倾、侧倾和靠背样本。保留原始人工历史。
2. 重新审核此前因复合姿势排除的条目。若属于“低头＋明确前倾/侧倾/后仰”，可按新规则给主类；不能自动恢复全部排除样本。
3. 将同学的 43 张后仰原图作为第五类候选逐张复核。目录中的卡通、躺卧、多人目标不明及重复编辑版本仍按相应理由处理。
4. 补齐目标人物框。原图和全部裁剪、同一视频以及已知同一场景/拍摄关联图保持同组；现有 160×160 拉伸裁剪从原图重新等比处理。
5. 导出双方共用的版本化清单。保留来源、目标框、主标签、辅助头部状态、视角、内容组、原标签、复核人和规范版本。双方采用同一训练/验证/测试分配文件。
6. 已用于筛选、规则讨论与开发的图片继续用于训练/开发。最终测试从新增隔离组中预留；未知身份不视为已经完成跨人隔离。

当前训练代码固定为四类，审核页已能显式选择五类新审核。落实五类训练时，仍应同步修改训练清单校验、模型输出、规则基线、评估标签顺序和演示端，重新生成带版本的特征缓存与模型；仅增加一个目录不会完成迁移。

五类数据标准可以先统一。若某一类暂时无法形成足够清楚、来源多样的样本，应继续定向补充；需要做四类先导实验时，双方从同一五类清单明确导出一致的四类子集，并记录该实验范围。
